# SignPicture テストシナリオ

## テスト環境

| 項目 | 値 |
|------|-----|
| MODバージョン | 3.0.0 |
| 対応MC | 1.20.1 (Forge/Fabric), 1.21.1 (Fabric/NeoForge) |

## 1. MOD読み込みテスト

### 1.1 起動確認
- [ ] Minecraftが正常に起動する
- [ ] MOD一覧にSignPictureが表示される
- [ ] アイコンが正しく表示される
- [ ] コンソールにエラーがない

### 1.2 ログ確認
- [ ] `[SignPicture] SignPicture initialized` が出力される
- [ ] `[SignPicture] Client initialized` が出力される

## 2. コマンドテスト

### 2.1 ヘルプコマンド
```
/signpic
```
- [ ] コマンド一覧が表示される

### 2.2 ステータスコマンド
```
/signpic status
```
- [ ] キャッシュ画像数が表示される
- [ ] アクティブエントリ数が表示される
- [ ] バージョンが表示される

### 2.3 キャッシュクリアコマンド
```
/signpic clear
```
- [ ] クリア完了メッセージが表示される
- [ ] キャッシュ数が0になる

### 2.4 リロードコマンド
```
/signpic reload
```
- [ ] リロード開始メッセージが表示される

## 3. キーバインディングテスト

### 3.1 キー設定確認
- [ ] 設定 → 操作設定 → SignPictureカテゴリが存在する
- [ ] 「Open SignPicture GUI」キーが表示される (デフォルト: バックスラッシュ `\`)

### 3.2 キー動作確認
- [ ] ゲーム中に `\` キーを押すとGUIが開く
- [ ] GUI画面中はゲームが一時停止しない
- [ ] ESCキーでGUIが閉じる

### 3.3 キー変更テスト
- [ ] 別のキーに変更できる
- [ ] 変更後のキーでGUIが開く

## 4. GUIテスト

### 4.1 GUI表示確認
- [ ] タイトル「SignPicture」が表示される
- [ ] バージョン番号が右上に表示される
- [ ] URL入力フィールドが表示される
- [ ] 4つのボタンが表示される (Load Image, Clear Cache, Reload, Close)

### 4.2 URL入力テスト
- [ ] テキストフィールドにURLを入力できる
- [ ] 長いURLも入力できる (2048文字まで)

### 4.3 ボタン動作テスト

#### Load Imageボタン
```
テストURL: https://i.imgur.com/xxxxx.png
```
- [ ] URLを入力してLoad Imageを押すと読み込みが開始される
- [ ] ステータスメッセージが表示される

#### Clear Cacheボタン
- [ ] キャッシュがクリアされる
- [ ] クリア数が表示される

#### Reloadボタン
- [ ] テクスチャリロードが実行される

#### Closeボタン
- [ ] GUIが閉じる

## 5. 看板画像表示テスト

### 5.1 基本表示テスト
1. 看板を設置
2. 看板に画像URLを入力 (例: `https://i.imgur.com/xxxxx.png`)
3. 確認項目:
   - [ ] 画像がダウンロードされる
   - [ ] 看板に画像が表示される
   - [ ] 看板から離れても画像が見える

### 5.2 キャッシュテスト
1. 画像付き看板を表示
2. ワールドを再読み込み
3. 確認項目:
   - [ ] キャッシュから画像が読み込まれる
   - [ ] 再ダウンロードが発生しない

### 5.3 複数画像テスト
1. 複数の看板に異なる画像URLを設定
2. 確認項目:
   - [ ] 全ての画像が正しく表示される
   - [ ] パフォーマンスが安定している

## 6. エラーハンドリングテスト

### 6.1 無効なURL
```
テストURL: https://invalid.example.com/notfound.png
```
- [ ] エラーが適切に処理される
- [ ] クラッシュしない

### 6.2 非画像URL
```
テストURL: https://example.com/
```
- [ ] エラーが適切に処理される

### 6.3 ネットワークエラー
- [ ] オフライン時にクラッシュしない
- [ ] キャッシュがある場合は表示される

## 7. リソースパック再読み込みテスト

### 7.1 リソースパック変更時
1. 画像付き看板を表示
2. F3+T でリソースを再読み込み
3. 確認項目:
   - [ ] テクスチャが再読み込みされる
   - [ ] 画像が正しく再表示される

## 8. マルチプレイテスト

### 8.1 サーバー参加
- [ ] サーバーに参加できる
- [ ] 他プレイヤーの看板画像が見える

### 8.2 サーバー退出
- [ ] サーバー退出時にエントリがクリアされる

## 9. パフォーマンステスト

### 9.1 メモリ使用量
- [ ] 大量の画像表示時にメモリリークがない
- [ ] GCが適切に動作する

### 9.2 FPS影響
- [ ] 画像表示時のFPS低下が許容範囲内
